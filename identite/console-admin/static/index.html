Révoquer

  • Son compte d'identité est désactivé : plus aucune connexion possible.
  • Ses sessions sont fermées, sur tous ses appareils.
  • Il ou elle est retiré(e) de tous les salons et ne pourra plus lire les nouveaux messages.
  • L'historique reste disponible pour les autres membres.

    Enrôler un agent

    L'agent reçoit un mot de passe provisoire. À sa première connexion, il choisit son mot de passe et configure son code TOTP.
